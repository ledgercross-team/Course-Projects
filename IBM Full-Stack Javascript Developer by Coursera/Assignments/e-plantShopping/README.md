# 🌱 Paradise Nursery Shopping Application

Frontend e-commerce plant shopping application built with React and Vite as part of the Full-Stack Software Developer by Coursera program.

## Features

- Browse different categories of plants
- Add plants to shopping cart
- Increase and decrease product quantity
- Dynamic cart total calculation
- Responsive modern UI
- React component-based architecture
- Fast development setup using Vite

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS
- ESLint
