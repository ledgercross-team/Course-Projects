# 📚 Express Book Reviews API

Backend REST API project built with Node.js and Express as part of the IBM Full Stack JavaScript Developer Professional Certificate.

## Features

- JWT/session authentication
- User registration & login
- Add, modify, and delete reviews
- Search books by ISBN, author, and title
- Async/Await API routes
- RESTful backend architecture

## Tech Stack

- Node.js
- Express.js
- JWT
- Express Session
- JavaScript
