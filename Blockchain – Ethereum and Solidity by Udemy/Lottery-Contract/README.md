# 🎰 Lottery Contract DApp

A decentralized lottery application built with Solidity, Hardhat, React, TypeScript, Ethers.js, and MetaMask.

## Features

* Connect wallet using MetaMask
* Enter lottery by sending ETH
* View current lottery balance and participant count
* Manager-only winner selection
* Automatic prize distribution to the winner
* Smart contract interaction through Ethers.js
* Local blockchain development with Hardhat

## Tech Stack

* Solidity
* Hardhat
* React
* TypeScript
* Ethers.js
* MetaMask
* Vite

## Learning Objectives

* Smart Contract Development
* DApp Architecture
* MetaMask Integration
* Ethers.js Contract Interaction
* Local Blockchain Testing with Hardhat
